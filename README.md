# Competitive Programming Solutions

A collection of solutions to programming problems from Codeforces and other competitive programming platforms.

## Repository Structure

- Each solution is kept in its own source file.
- Solutions are grouped by problem or platform as the repository grows.
- Source files contain the complete program, including input handling and output.

## Running a Solution

Compile a Java solution:

```bash
javac Solution.java
```

Run the compiled program:

```bash
java Solution
```

Provide input according to the problem statement through standard input.

## Requirements

- Java Development Kit (JDK)
- A terminal or Java-compatible IDE

## Notes

Solutions are maintained for practice, learning, and future reference. They may use different approaches depending on the problem and its constraints.
